# Round 001：结论

## 决策

Round 001 完成，结论为“部分成功，继续 SFT 迭代”，暂不进入 DPO。

- 0.6B 严格通过数由 29/51 提升到 33/51，定向数据产生了实质收益；
- 1.7B 严格通过数保持 34/51，任务均分小幅提高，但尚未形成通过率收益；
- 1.7B 的工具调用已较稳定，0.6B 的 JSON 完整性和工具参数仍是主要短板；
- 两个模型都仍存在多轮状态继承和缺失信息动作边界问题；
- 本轮同时暴露并修复了预约成功场景的评分器冲突，正式结果已统一重算。

## 下一轮建议

1. 继续 SFT，不制作 DPO 数据；
2. 0.6B 加强短输出、严格 JSON、工具参数完整性训练；
3. 1.7B 加强枚举约束、缺失信息追问以及 final 状态字段训练；
4. 两个模型继续补强最小状态修改、相对日期和工具结果后的状态转换；
5. 下一轮把数据策略拆成更小的可归因分组，并保留回放集防止简单任务退化。

本轮没有达到“两个尺寸均显著提升”的目标，因此新 SFT 不替代全部历史基线；
0.6B 候选可作为下一轮父模型参考，1.7B 则应保留旧、新两版共同对照。
