# Round 003：策略与实验计划

状态：数据、配置与远端训练包已冻结，等待用户启动远端训练。

## 目标

在保留 Round 002 已获得能力的前提下，修复字段边界、相对日期、工具结果字段保真以及 final JSON 回归。

## 数据策略

`sft-v0.4` 的两个模型视图均为 1265 条，训练/验证切分为 1138/127：

- 完整继承 v0.2 的 795 条回放；
- 完整继承 Round 002 的 210 条共享样本；
- 各自继承 Round 002 的 80 条模型专项样本；
- 新增 120 条共享修复样本；
- 各新增 60 条模型专项样本。

新增共享样本覆盖：通用服务词与偏好槽位边界、相对日期与最小状态更新、工具结果完整字段映射、缺失信息与暂停动作回归保护。0.6B 专项继续强化短 tool-call 和参数完整性；1.7B 专项强化严格 final JSON、无关请求和工具结果映射。

数据构建器检查 ID 唯一、输入唯一、原始标签合法，并确保与冻结 eval-v0.2 精确输入重叠为 0。

## 训练控制

两个 run 均从原始 Qwen3 基座训练，不续训旧 Adapter。LoRA、学习率、epoch、batch、模板和随机种子全部保持不变，唯一实验变量是 `sft-v0.4` 数据。

## 成功标准

- 0.6B 严格通过至少 39/51；
- 1.7B 严格通过至少 38/51；
- 每个模型相对其最佳历史基线回归不超过 1 条；
- 两个模型不可解析 JSON 均为 0；
- 非法枚举为 0；
- 日期、preferences 和工具结果字段保真错误各不超过 1 条。

若仍未达到标准，先区分“模型容量限制”和“训练数据标签冲突”，不直接用 DPO 覆盖结构化错误。

## 结果包策略

常规结果包只带回训练日志、trainer state、训练/验证指标、loss 图、逐样本预测、评分卡和环境信息，不包含 Adapter、checkpoint 或 optimizer。先在本地分析效果；只有模型达到最终候选标准时，才在释放实例前单独下载对应 Adapter。
